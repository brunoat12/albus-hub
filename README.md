# Albus-Hub

Projeto acadêmico de AIOps voltado à previsão de incidentes,
análise de tendências operacionais, risco de quebra de OLA/SLA
e geração de alertas.

## Objetivos

- prever o volume de incidentes em D+1 e D+7;
- estimar o risco operacional dos chamados;
- criar um score de priorização;
- gerar alertas e recomendações;
- disponibilizar resultados em um dashboard.

## Tecnologias previstas

- Python
- Pandas
- Scikit-learn
- XGBoost
- Apache Airflow
- RabbitMQ
- Streamlit
- Docker
- GCP ou Azure
